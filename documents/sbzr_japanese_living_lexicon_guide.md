# 日本生活专属词库（地名/站名/人名/办事）维护与扩充指南

## 1. 词库定位与架构

在中文输入方案（`sbzr`）下，为了满足在日本生活、留学、工作期间输入**日本电车站名、都道府县市区町村、行政机构与常见日本人名**的需求，我们设计了独立的日本专属词库：

* **词库源文件**：[`sbzr.chrome.extension/dicts/sbzr.extended.japan.dict.yaml`](../sbzr.chrome.extension/dicts/sbzr.extended.japan.dict.yaml)
* **自动构建脚本**：[`scripts/build_japan_lexicon.py`](../scripts/build_japan_lexicon.py)
* **挂载位置**：[`sbzr.dict.yaml`](../sbzr.dict.yaml) 中的 `import_tables`

### 核心特性
1. **中文读音输入**：完全按照中文汉字注音打字（如输入 `segu` / `sbgu` 打出「涩谷/渋谷」，输入 `gtmc` 打出「高田马场/高田馬場」）。
2. **简繁日汉字并存**：常用站名与人名同时生成**简体中文**与**日文原汉字**（日文原汉字自动继承对应简化字的拼音）。
3. **声笔自然双编码**：自动派生 **4 码公式**（声1+声2+声3+末声）与 **全双拼兼容码**。
4. **零性能损耗**：独立解耦，不污染中文核心基础库，内存占用小，响应零延迟。

## 2. 如何扩充新词（三种方式）

### 方式一：直接找 AI 助手（最推荐、最省心）
当你发现某个平时常去的车站、冷门区町、特定办事机构或朋友姓名打不出来时，**直接把词发给 AI**：
> “帮我把‘押上’、‘清澄白河’、‘门前仲町’、‘东武晴空塔线’加到日本专属词库里。”

AI 会自动处理汉字注音、派生 4 码/全双拼编码、生成日汉字对照，并自动重新编译部署生效。

---

### 方式二：通过构建脚本批量添加（适合批量管理）

1. 打开构建脚本 [`scripts/build_japan_lexicon.py`](../scripts/build_japan_lexicon.py)；
2. 在 `raw_data` 数组中追加你想添加的词条与权重（推荐权重 `2000~2500`）：
   ```python
   # 示例：追加新车站或地名
   ("晴空塔", 2300), ("スカイツリー", 2100),
   ("二子新地", 2200),
   ("高津", 2200),
   ```
3. 运行构建脚本生成词典：
   ```bash
   python3 scripts/build_japan_lexicon.py
   ```
4. 重新编译 Rime 并生效：
   ```bash
   ./rebuild && killall Fcitx5 && sleep 1 && open -a "/Library/Input Methods/Fcitx5.app"
   ```

---

### 方式三：临时快速添加单条（命令行一键添加）

如果只是临时想快速添加 1~2 个词，可以使用项目内置的 `./add-word` 工具直接写入快捷词库：

```bash
# 语法：./add-word <词条> [自定义编码] [权重]
./add-word 高津 gaju 2000
./add-word 晴空塔 qkdt 2200
```

## 4. 同步与跨设备部署

当你在本地添加并修改词库后，按标准流程同步即可分发到所有设备（Windows / macOS / Linux）：

```bash
# 1. 提交并推送到 GitHub
git add sbzr.chrome.extension/dicts/sbzr.extended.japan.dict.yaml scripts/build_japan_lexicon.py
git commit -m "feat(dict): add new Japanese place names"
git push origin main

# 2. 在其他设备上拉取并重新部署
git pull
./rebuild   # 或在 Windows 小狼毫上点击“重新部署”
```
